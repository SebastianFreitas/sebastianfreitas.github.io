When working on this project: do architecture, planning, and code review yourself.
Do not write implementation code directly.

For actual coding, delegate to Sonnet 5. Give it fully spelled-out instructions —
exact function/method names, file paths, logic steps — so it never has to reason
about design or syntax on its own.

Spin up sub-agents only if doing so would genuinely save tokens versus writing the
code yourself directly. If delegating would cost more than it saves, just write it
yourself with no agents.
